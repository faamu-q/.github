# Support

Use the channel that matches the request:

- **Bug:** open a Bug Report.
- **Feature:** open a Feature Request.
- **Research idea:** open a Research Proposal.
- **Model evaluation:** open a Model Evaluation issue.
- **Security issue:** follow `SECURITY.md` and do not post sensitive details publicly.
- **General question:** use GitHub Discussions when enabled.

Please include enough technical context to reproduce or evaluate the request.
FAAMU does not guarantee support for unofficial forks, unsupported environments
or modified model artifacts.
