# FAAMU Brand Notes

## Identity

- **Company:** FAAMU
- **Flagship model:** FAAMU Q
- **Primary namespace:** `faamu-q`
- **Primary visual direction:** minimal, modern, yellow + charcoal

## Working colors

The current logo uses a warm yellow. For digital assets, use the following as a
working reference until a formal design system is adopted:

- Yellow: `#E8A004`
- Charcoal: `#171717`
- White: `#FFFFFF`

## Usage

Use **FAAMU** when referring to the company or organization.

Use **FAAMU Q** when referring to the language-model family.

Avoid:
- `FAAMU AI` as the model name;
- legacy or unrelated branding in FAAMU repositories;
- decorative finance-chart motifs as primary brand elements;
- multiple competing yellow shades in the same asset.

Brand assets are stored in `profile/assets/`.
